## `04 / ENGINEERING_METHODS`

### Context Engineering

Designing and structuring the information, instructions, knowledge, tools, and state that an AI system needs to perform a task reliably.

### Prompt & Harness Engineering

Designing the prompts, execution environment, tools, constraints, verification mechanisms, and supporting infrastructure around AI systems.

### Loop Engineering

Building iterative workflows in which systems repeatedly execute, observe results, evaluate outcomes, incorporate feedback, and improve toward a defined objective.

```text
        ┌───────────────┐
        │   OBJECTIVE   │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │    EXECUTE    │
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │    OBSERVE    │
        └───────┬───────┘
                ↓
        ┌───────────────┐
```
